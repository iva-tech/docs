# HedgeDoc Codium Extension

This extension provides simple commands for working with HedgeDoc files.

- `hedgedoc.open` shows a welcome message.
- `hedgedoc.editFile` prompts for a file located in the repository given by `hedgedoc.CompanyGitID` and opens it.
- `hedgedoc.saveToGit` saves the active file and commits it to that repository.

Run `npm install` and `npm run package` inside this folder to produce a `.vsix` file.
